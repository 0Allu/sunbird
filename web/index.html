Phoenix Unlock

Patches Discord's new native client (Phoenix) so it opens without the access gate, with staff tools turned on. It all runs in this browser; nothing is uploaded.

Plugins

Your plugins run on the built-in runtime (phoenix API, plain scripts; on arm64 phoenix.native.intercept hooks native code through ShadowHook; types in phoenix.d.ts). The first line // Name: what it does names it in Settings → Phoenix. Optional: pick .js files and/or write one below.

Frida scripts run inside Discord when it starts (Frida 17 API with Java, plain scripts without imports). The ones you pick here are installed on first start; in the app, the floating JS button opens a panel to turn plugins on and off, add more from a URL, reload them, and see their console.
