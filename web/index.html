Phoenix Unlock

Patches Discord's new native client (Phoenix) so it opens without the access gate, with staff tools turned on. It all runs in this browser; nothing is uploaded.

arm64 (64-bit phones)

    
  
    

  
    
    
    Automatic download isn't available. Download these files, then pick all of them below.
    
    
      
    
  
      

  
      
    Download patched APK
    
      1. Uninstall Discord first if it came from the Play Store; Android won't update an app signed with a different key.
      
    2. Open the downloaded file and allow your browser to install apps if asked.
      
    3. Later builds: patch again in this same browser. It keeps your signing key, so the new APK installs as an update and you stay logged in.
